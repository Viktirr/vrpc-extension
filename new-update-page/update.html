VRPC 1.1.0 is here

VRPC can now check for, download and verify updates by itself.

The app still asks before installing by default. If you prefer, you can let it install verified updates automatically instead.



Automatic updates

What happens when you enable it:

  • VRPC checks a signed release feed in the background.
  • Downloads are checked against the signed size, SHA-256 and every payload file before anything runs.
  • When a verified update is ready, VRPC closes, installs it and restarts. Settings and listening history are kept.
  • If an install fails, the previous version is restored and VRPC keeps working.

You can change this at any time in the extension popup under Configuration → Updates. The Update now button remains available either way.

Thank you for using VRPC!
